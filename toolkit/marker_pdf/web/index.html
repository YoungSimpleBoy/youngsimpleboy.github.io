说明

使用提示

  • 先用页码范围 0-2 试跑，再决定是否全文转换。
  • 页码范围遵循 marker 规则，通常从 0 开始。
  • “文本优先”适合可复制文字的 PDF，会自动跳过 OCR 和图片提取。
  • 输出目录下会生成“PDF 文件名/文件名.md”这类结构。
  • 转换过程依赖本机已安装的 marker_single。
